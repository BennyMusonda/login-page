# Custom Login Page with Preloader

A clean, modern, and responsive **Login Page** featuring an animated **Preloader** and a smooth transition to a **Welcome Dashboard** upon authentication. Built entirely from scratch using vanilla web technologies.

##  Features
*   **Animated Preloader:** A smooth loading screen that disappears automatically once the DOM content has fully loaded.
*   **Modern Login UI:** A stylish, centered login card featuring optimized form fields for user credentials.
*   **Welcome Dashboard:** A seamless transition to a dedicated landing view after successful user authentication.
*   **Fully Responsive:** Fluid layouts designed to fit beautifully across mobile, tablet, and desktop screens.
*   **Interactive Enhancements:** Styled focus states, button hover transitions, and clean form validation powered by JavaScript.

##  Live Demo
Experience the project live in your browser: [View Live Demo](https://bennymusonda.github.io/login-page/)

## 🛠️ Technologies Used
*   **HTML5:** Component structures for both the login portal and the post-auth dashboard views.
*   **CSS3:** Flexbox layouts, media queries for full responsiveness, and smooth transitional animations.
*   **JavaScript (ES6):** Logic handling the preloader lifecycle, page transitions, and authentication flows.

##  Project Structure
```text
├── imgs/               # Directory housing project asset images
├── index.html          # Portal entry point containing the preloader and login form
├── styles.css          # Core stylesheet handling login portal layout and animations
├── welcome.html        # Target dashboard view loaded after authentication
├── welcome.css         # Dedicated styling for the welcome dashboard interface
└── welcome.js          # Client-side interactivity and logic for the welcome view
```

##  How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project directory:**
   ```bash
   cd login-page
   ```
3. **Launch the application:**
   Double-click the `index.html` file to instantly run it within your preferred local web browser.
